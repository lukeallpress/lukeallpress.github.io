The future of edtech isn't every product bolting on its own chatbot — it's district-owned agents that can coordinate work safely across the systems we already run.

This project is an early step toward that: an MCP (Model Context Protocol) server built in-house to give AI agents a controlled, well-defined way to interact with district tools. The point isn't to hand agents the keys — it's the opposite. Real APIs, delegated permissions, and audit trails mean we can begin to automate genuinely useful tasks while keeping a human-understandable boundary around what an agent can and can't do.

It's infrastructure for a careful version of the agentic future — owning the orchestration layer rather than renting it.
