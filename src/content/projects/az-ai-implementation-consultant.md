Statewide AI guidance is only useful if a district can translate it into action. This is a prototype of an agentic platform that does exactly that: it takes the Arizona GenAI Guidance and helps a district build a tailored implementation plan grounded in the official document.

Under the hood, five specialized agents work together under one orchestrator — interviewing staff across different roles, crawling the district's own website to assess readiness, and generating a section-by-section plan with citations back to the AZ GenAI Guidance (v26.01). Every recommendation is attributed to the conversations and sources that produced it.

The published version is a **read-only static preview**: it shows real output from the planning agent using invented district data, illustrating what the full platform produces. The live system needs server infrastructure and API access to run end to end.
